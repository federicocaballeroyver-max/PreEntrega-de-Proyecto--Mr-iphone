Mr iPhone
Pre-entrega del proyecto de Front-End. Es una pagina web para Mr iPhone, un negocio de venta de iPhone usados en Caballito.
Es el "emprendimiento" de un familiar mio al cual le pedi permiso para tomarlo como inspiracion para el protecto.
Muestra algunos celulares e informacion que saque toda de la cuenta de instagram, todo publico por las dudas.
